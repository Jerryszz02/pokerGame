# 练习产品实施与验收记录

历史记录：本文保留 2026-09-10 练习功能实施时的决定、Mono 引擎命令与本地验收结果；该功能随后随 v1.1.0 发布。当前版本、CI 与公开发布状态见[规划入口](README.md)，现行固定引擎和命令见 [Runbook](../runbook.md)。

需求入口：[practice-product-plan.md](practice-product-plan.md)。用户于 2026-09-10 确认实施 P1～P5 的非算法功能及下列默认方案。本文件记录本次实施决定和实际验证，不代表公开版本已发布。

## 已确认的决定

- 盲注提供 5/10、10/20、25/50、50/100；每人筹码提供 1000、2000、5000、10000。一场内固定，不增加补筹码或升盲。
- 教程采用 T1～T7，预设对手动作继续经过规则引擎；教程不累计普通战绩。
- 最多保留 1000 手牌谱。达到容量后提示玩家手动清理并重试，不自动删除。删除牌谱保留累计统计与已解锁成就。
- 首批成就为首次完成课程、全部入门课程、完整回放、正常摊牌形成葫芦/四条/同花顺，以及筹码达到入场时的两倍。辅助来源单列。
- 练习模式本次交付基础流程；新教练、难度/性格算法和画像维度仍待后续定义。不可用状态不得提供虚构建议、概率或雷达评分。

状态：**非算法范围已实现并通过本地验收**。P5 是基础练习流程，未实现后续算法。

## 实现边界

1. 配置在开桌时复制进入规则引擎；所有筹码支付、最小加注和结果都使用该快照。
2. 规则层保存结构化动作及街道检查点。回放仅渲染深拷贝，不复用正在进行的权威牌局，也不重新统计。
3. 本地存储区分偏好、旧历史汇总、教程进度、逐手文件和累计账目。提交使用唯一手牌标识，失败可重试；未知版本不能静默覆盖。
4. 页面层负责导航、配置草稿、教程选择、记录与统计筛选、回放及保存反馈。AI 结果仍通过当前场次/手牌/行动者校验。

## 剩余边界

- AI 在不同筹码尺度下的强度/打法一致性未专项验收；本次只证明配置及行动合法性生效。
- 教练的加载/计算失败/结果展示需随真实算法接入；当前只有明确不可用、重试和关闭流程，不显示虚构结果。画像维度/评分未定义。
- 不恢复进行中的整场；应用退出前仍未保存的内存提交可能丢失，会明确提示。
- 紧凑累计账目随手数增长；1000 手容量限制针对完整逐动作牌谱。删除牌谱不删除累计账目或成就。
- 本次未构建或公开上传桌面发行包。源码、PR、CI 与公开下载分别验收。
