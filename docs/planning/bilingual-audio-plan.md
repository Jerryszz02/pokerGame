# 中英文切换与音频方向

日期：2026-09-11。用户已确认实施设置内中英文切换；用户随后确认轻柔爵士 / Lounge 风格，音频纳入本轮实施。Web、itch.io 上传沿用前轮计划，本轮不将其视为已实现。

## 本轮交付

- Godot 内置翻译资源，支持简体中文和 English；设置提供跟随系统、简体中文、English。
- 首次中文系统使用中文，其余语言回退英文；手动选择持久化，旧配置安全补默认值。
- 覆盖菜单、对局、设置、帮助、教程、历史回放、统计和成就。对局中切换仅改变展示，不改变牌局与 AI 状态。
- 动态模板先翻译再代入参数。内部规则代码、动作 ID、牌型比较、玩家身份保持语言无关。
- 旧牌谱优先由已有结构化字段生成本地化展示；已知旧标签可精确映射，无法还原的历史原文保留，不批量改写用户文件。
- 两个平台导出都包含翻译资源。公开发行包仍以对应 Release 为准，PR 不等于新版本上线。

## 实施顺序

1. 语言资源、选择持久化和设置入口。
2. 全路径静态/动态文案接入及旧记录兼容。
3. 语言切换、存档、模板参数和 UI 回归；检查 1280×720 英文布局。
4. 文档同步、diff 检查、提交与 ready PR。

## 验收

- 中英互切及时更新，重开记住选择；未知系统语言与坏设置安全回退。
- 对局中切换保留同一牌局、筹码、当前行动者及暂停状态。
- 菜单、帮助、教程、对局、回放和统计可用，无翻译键泄露及关键英文文案截断。
- 保持既有规则测试通过；新增本地化测试；实际 UI 结果与自动探针分别记录。

## 音频调查

现有音效由 `AudioStreamGenerator` 实时合成正弦波及衰减，没有独立音频文件；未发现背景音乐资源。候选方案是一首低音量循环背景音乐，加按钮、发牌、弃牌、筹码及结算短音效，音乐和音效独立控制。现已选定 Airport Lounge 与 Kenney Casino Audio，接入本地音频文件、分别持久化音乐/音效音量与署名入口；不把授权网页核对描述为听感验收。

优先作者站或明确作者发布的 CC0 素材；需要署名的作品保留准确署名与许可证。只将实际采用的素材写入 THIRD_PARTY_NOTICES，不给整个来源网站一概标注可商用。AI 音效是缺少合适素材时的备选，本轮没有生成。

- Kenney Casino Audio：https://kenney.nl/assets/casino-audio （页面标注 CC0）
- Kenney 授权说明：https://kenney.nl/support

### 音频来源与候选（试听体验验收另记）

背景音乐只选一首开始，低默认音量，检查循环接缝、长时间重复的疲劳感及与筹码音效的层次。音效先覆盖按钮/发牌/弃牌/下注/结算，不为每个动作强行堆叠音效。后续若采用 AI 生成，应单独核对实际服务和账号方案的商用条款；本轮未调用生成服务。

## 实施结果与本地验收（2026-09-11）

- 翻译源集中为 375 条 CSV 记录；动态显示先翻译模板，再代入数值。教程七课全部步骤、配置页、牌桌/日志、摊牌、历史、逐帧回放和统计已通过英文残留检查。中文首页保留原标题图，英文使用原生文字标题。
- 已有牌局/存档保留原格式。`GameLocalization.message()` 仅识别规则引擎生成的完整句式，旧牌谱未知原文原样保留；不批量替换或迁移玩家文件。游戏与 AI 规则未改动。
- 设置支持语言和音乐/音效独立音量；音效开关保留。旧配置若关闭音效，新增音乐默认静音。音乐和效果资源在两平台预设中显式列入，许可证会随桌面构建打包，设置提供音频署名入口。
- 使用实际 Godot `4.7.2.stable.official.ed1daf0bf`：`tools/verify.py` 完整 headless 检查通过，包括新增语言/catalog 参数一致性、全路径语言 UI、音频资源/持久化测试，以及既有规则、存档、教程、AI、长规则采样和 UI 布局/生命周期检查。
- 有窗口的 `localization_ui_probe.gd`、原有 `ui_playthrough_probe.gd`、`practice_ui_probe.gd` 通过；实际查看 1280×720 菜单、教程、牌桌和统计截图。窄盲注标记在英文中使用 SB/BB。
- 额外本地音频 UI 检查验证音乐播放、音乐暂停/恢复、音效独立开关与滑块；清理后无资源泄漏错误。音效技术播放检查不是主观听感验收，长时间循环听感仍可由玩家试听反馈。

- 全新 Git 检出（无 `.godot` 缓存）的完整验证和 `tools/build_release.py --target macos` 均通过，构建后工作区仍干净。两份启动必需的 `.translation` 资源已跟踪，避免首次导入缺失。
- macOS 候选导出包的实际可执行程序通过 `--headless -- --self-test`，确认 `template=true`、中英文翻译和全部音频资源可用，9 种配置及统计幂等检查通过。Windows 包由 PR CI 验证。
