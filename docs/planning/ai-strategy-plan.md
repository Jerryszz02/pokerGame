# 起手范围、对手范围与行动收益

来源：2026-09-10 用户要求在现有 AI 上补全这三项能力，保持免费、完全本地；CFR 留待后续决策。本文维护算法边界和验收要求，实际接口与限制随代码更新到 [架构说明](../architecture.md)。

状态：本轮算法与回归已实现；2026-09-10 本地完整验证含窗口流程通过。该状态不代表已合并、公开发布或通过专业棋力评测。

## 本轮范围

1. 覆盖全部 169 类起手牌，用位置、人数、前序加注、跟注价格和有效筹码深度计算开池、继续和再加注频率。
2. 根据本手已经发生的公开行动推断每名对手的加权手牌范围，尊重已知牌阻断；不读取真实底牌、对手配置或内部决策理由。
3. 翻后对合法弃牌、过牌、跟注和多种加注尺度比较近似收益，处理弃牌率、多人参与、全下与边池资格。
4. 分开性格与难度：性格控制入池松紧、进攻倾向、诈唬和跟注容忍；难度控制计算预算与选择误差。保留五种已有性格与三档难度的兼容入口。

首页、教程、筹码/盲注选择、性格选择界面、回放、教练 UI、统计和成就不在本 PR 中。算法为这些后续功能提供本地接口，不修改另一任务的产品流程。

## 设计约束

- 行动仍只通过 `PokerRound.apply_action()` 提交，摊牌仍用 `HandEvaluator.evaluate()`。困难翻前使用 `StartingHandTable`，翻后使用 `MonteCarlo`，性格来自 `PersonalityProfiles`。
- 起手范围是启发式频率模型，不能标注为求解器、GTO 或职业标准表。旧起手评分保留兼容，但不能当作真实胜率。
- 新增逐手公开行动记录，与供 UI 使用的文字事件日志分开；只记录成功行动，保存行动当时的公共牌和价格，下一手重置。
- AI 线程使用白名单快照；除行动者自己的牌与配置之外，只包含公共信息。推断范围时不能用后来发出的牌解释早前行动。
- 对手范围采用有非零支持的加权组合，依公开行动累计更新；不把诈唬可能性削成零。联合抽样不能让两个对手拿到同一张牌，也不能使用真实牌堆。
- 收益使用“当前行动 → 对手一轮弃牌/跟注回应 → 发完公共牌摊牌”的有限模型。回应只能基于当时已知牌，不能根据抽样的未来牌决定跟注。
- 收益单位为筹码，基准为当前决策点；已投入筹码是沉没成本。计算本人可赢的各层底池和未匹配筹码返还，再扣新增投入；不能把整池权益乘以自己无资格赢的边池。
- 候选行动必须合法；不得通过模拟结果绕过最小加注、加注权或有效筹码限制。个性在合理候选之间产生偏好，不能把更多随机错误当成更鲜明的打法。
- 使用独立可设种子的随机源，不干扰实际发牌。参数需校验有限数值并限制计算预算，缓存不能在多个线程之间共享可变状态。

## 验收要求

| 范围 | 必须证明 |
| --- | --- |
| 起手范围 | 169 类完整覆盖；位置、单挑、再加注、筹码深度和松紧参数产生合理差异；筹码与盲注等比例缩放不改变判断。 |
| 信息边界 | 无效行动不入记录；历史快照深拷贝且逐手清空；修改对手隐藏牌、配置与内部理由不能影响固定种子下的判断。 |
| 范围抽样 | 已知牌与对手间无重复；公开强势行动可收紧范围；平分计入权益；未知弃牌者底牌不可读取。 |
| 行动收益 | 已知结果可解析核对：免费过牌、付费跟注、所有对手弃牌、平分、短筹码全下、边池与未匹配投入返还。 |
| 风格与合法性 | 固定种子批量场景下，松/紧和主动/被动有可测差异；三档难度始终输出可提交行动；异常参数不会失控。 |
| 回归与性能 | 现有规则、10,000 手规则 soak、后台 AI 生命周期和 UI 探针通过；记录现有 AI benchmark 的前后耗时，不能用降低测试要求掩盖退化。 |

## 训练效果边界

这一阶段可支持起手纪律、针对不同风格和不同价格的基础练习。它不包含完整后续街道博弈、对手再加注、长期对手学习或均衡求解，不能将有限模型的最高收益称为全局最优行动。

自动化正确性、运行性能、风格差异与实战强度分开验收。通过前者不代表击败资深玩家。职业级训练效果仍需独立基准、固定牌局对照、足够样本与人工评估，尚未验证。

可自定义参数的数学组合数量不是有意义的对手数量；第一阶段以五种可辨认风格作为基础，新增风格需要行为统计支持，不能只换名称或微调数值。
