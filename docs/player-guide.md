# PokerGame 玩家说明

这是中文离线单人德州扑克，支持 1–5 个 AI 和简单、中等、困难三档难度。没有账号、联网、真实货币或后台数据收集。

## 候选发行包说明

当前正在首发验收，候选包不代表全部发布门已经通过。目标是 Windows x64 和 macOS Apple Silicon；macOS 包使用官方 Universal 模板，包含 Intel 二进制不代表 Intel 已完成测试。最低系统要求与最终公开下载入口以正式发布说明为准。当前 macOS 候选包为 ad-hoc 签名，尚未公证；下载后的系统安全校验仍待完成。

Windows：完整解压压缩包后启动 `PokerGame.exe`。macOS：解压后打开 `PokerGame.app`，也可以把它移到“应用程序”目录。运行不需要 Godot 编辑器、.NET 或项目源码。默认以最大化窗口打开，可用窗口按钮还原或调整大小；至少需要 1280×720 的显示区域；当前渲染使用 Godot Mobile 渲染器，需要兼容的图形驱动。

## 开始与目标

选择对手数量和难度，点击“开始牌局”。每人初始筹码 1000，大小盲固定为 10 / 20；赢得所有筹码获胜，你的筹码归零时结束本局。菜单和设置中都有“玩法说明”。

每手使用两张底牌及最多五张公共牌，选最强的五张比较。让牌免费继续；跟注补足当前下注，筹码不足时只付剩余筹码；“加注到”显示的是本轮累计投入目标；全下投入全部剩余筹码，仍须符合加注权限制。

结算的“+金额”是获得的底池返还，不等于净利润。净利润要扣除本手投入；未被跟注的筹码单独退回。短筹码玩家只能赢对应的主池，其他投入形成边池。完全相同的牌分池，余数按庄位之后的座位顺序分配。

## 设置、暂停和本地数据

设置可切换音效、正常/快速行动，并查看与重置聚合战绩。打开设置、玩法说明、记录或暂停时，AI 会等待。关闭后继续。

当前对局不保存；返回菜单或退出会放弃当前对局及未结算手牌，界面会明确提示。已结算战绩及偏好会保留，新的对局重新从 1000 筹码开始。保存失败会提示，不会伪装成保存成功。

本地数据路径：

- Windows：`%APPDATA%/Godot/app_userdata/PokerGame/poker_profile.cfg`
- macOS：`~/Library/Application Support/Godot/app_userdata/PokerGame/poker_profile.cfg`

无需手动删除存档；重置统计请使用设置中的两步确认。
