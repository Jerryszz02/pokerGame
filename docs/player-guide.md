# PokerGame 玩家说明

这是中文离线单人德州扑克，支持 1–5 个 AI 和简单、普通、困难三档难度。没有账号、联网、真实货币或后台数据收集。

## 发行包说明

提供 Windows x64 和 macOS Universal 包。macOS 包包含 Apple Silicon 与 Intel 二进制，Intel 尚未单独验证。Windows 包未签名；macOS 使用 ad-hoc 签名，未经过 Apple 公证。系统可能显示首次启动安全提示；平台验证范围与下载入口以该版本正式发布说明为准。

Windows：完整解压压缩包后启动 `PokerGame.exe`。macOS：解压后打开 `PokerGame.app`，也可以把它移到“应用程序”目录。运行不需要 Godot 编辑器、.NET 或项目源码。默认以最大化窗口打开，可用窗口按钮还原或调整大小；至少需要 1280×720 的显示区域；当前渲染使用 Godot Mobile 渲染器，需要兼容的图形驱动。

## 从首页开始

以下功能适用于 1.1.0。使用旧版 1.0.0 的玩家需要下载新版压缩包并重新解压。

首页提供“新手教程”“自由对战”“练习对局 · 基础流程”。自由和练习模式先配置 1～5 个对手、三档难度、每人 1000/2000/5000/10000 筹码及四组固定盲注。取消保留草稿，点击开始才开桌。BB 表示大盲单位。赢得所有筹码获胜，筹码归零则整场结束；可免费重新开桌。

教程有七课，按提示实际选择区域、组合牌型、执行行动和理解结算。完成的课程可重练，进度独立保存。设置中可以随时打开规则速览与牌型速览。

练习可选择逐手暂停；关闭逐手暂停后，结算停留三秒再发下一手，打开覆盖层会暂停计时。本地教练尚不可用，不提供虚构建议或胜率。画像维度尚未定义，不显示雷达评分。

每手使用两张底牌及最多五张公共牌，选最强的五张比较。让牌免费继续；跟注补足当前下注，筹码不足时只付剩余筹码；“加注到”显示的是本轮累计投入目标；全下投入全部剩余筹码，仍须符合加注权限制。

结算的“+金额”是获得的底池返还，不等于净利润。净利润要扣除本手投入；未被跟注的筹码单独退回。短筹码玩家只能赢对应的主池，其他投入形成边池。完全相同的牌分池，余数按庄位之后的座位顺序分配。

## 设置、暂停和本地数据

设置可切换音效、正常/快速行动，并查看或二次确认重置旧版历史汇总。新统计与成就在首页的独立页面，支持模式、辅助来源、难度、人数和入场 BB 深度筛选。打开设置、玩法说明、记录或暂停时，AI 会等待。关闭后继续。

当前对局不保存；返回菜单或退出会放弃当前对局及未结算手牌，界面会明确提示。已成功保存的完整牌谱、累计记录及偏好会保留，新桌使用配置页所选筹码。保存失败会提示，不会伪装成保存成功。

本地数据路径：

- Windows：`%APPDATA%/Godot/app_userdata/PokerGame/poker_profile.cfg`
- macOS：`~/Library/Application Support/Godot/app_userdata/PokerGame/poker_profile.cfg`

同一目录下的 `poker_practice/` 保存教程进度、逐手牌谱、成就和新累计统计。旧汇总标注为“无法追溯”，不编造明细。

完成一手即可“复盘本手”，或从首页进入“牌局记录”。回放可逐步、自动播放、跳转实际发生的街道，并切换当时视角/全知视角；重复回放不重复计账。全知视角只对已结束牌谱开放。完整遍历所有步骤后解锁首次回放成就。

最多保留 1000 手完整牌谱。满后由你在记录页选择旧记录并确认删除，累计统计与成就保留；之后可重试保存。保存失败会明确提示，退出前请重试，未保存的内存更新会随退出丢失。无需手动删除存档。
