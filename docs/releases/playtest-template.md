# 可选真人试玩记录模板

这是待填写的可选产品反馈记录，不代表任何人已经试玩。用户于 2026-09-07 将 [R8](../planning/release-plan.md) 移出 Goal，不再要求人数或时长；必需的 R7 技术验收见 [运行手册](../runbook.md)。每位试玩者单独复制填写；只使用“试玩者 A/B”等匿名标识，不收集真实身份。

## 包与设备

- 试玩者标识、是否熟悉项目：
- 开始/结束时间：
- 系统版本、CPU/架构、显卡、显示分辨率与缩放：
- 包文件名、来源链接、SHA-256、对应提交：
- 是否安装 Godot/.NET（玩家不应需要）：
- 下载、解压、启动时系统显示的提示；是否成功进入菜单：

Windows 可用 `Get-FileHash .\PokerGame-1.0.0-windows-x64.zip -Algorithm SHA256`；macOS 可用 `shasum -a 256 PokerGame-1.0.0-macos-universal.zip`。先按包内 README 操作；遇到系统拦截就记录原文，不要求关闭系统防护。

- 帮助是否解决疑问；哪些词看不懂：

## 后续连续试玩

- 选择的人数、难度、正常/快速节奏：
- 中文与花色是否完整，文字是否够大，是否有遮挡或按钮点不到：
- AI 思考时打开记录、帮助、设置、暂停，关闭后是否正确继续：
- 完成一手、下一手、全下与结算；是否出现卡死、崩溃或疑似筹码错误：
- 返回菜单、开始新局；旧 AI 行动是否影响新局：
- 切换音效/节奏，退出并重开；设置与已结算战绩是否保留：
- 离桌提示是否让你理解“当前对局不保存”：
- 在不连接网络的设备/已有离线状态下，能否启动并完成一手（不用为测试更改他人的网络设置）：
- 等待是否难受；是否愿意再玩一局；最希望先改的一件事：
