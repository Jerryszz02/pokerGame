# PokerGame 1.4.0

Released to [itch.io](https://jerryszz02.itch.io/poker-game) on 2026-09-23.
This release replaces the seven-lesson beginner tutorial with three playable teaching hands: follow the coach, learn to fold, then make your own decisions.
See the [illustrated devlog](1.4.0-devlog.md).

## Verification

- Full `tools/verify.py` checks passed, including rules, AI, tutorial, save retry, localization, audio, layout and soak checks.
- Windowed tutorial probes passed at 1280×720, 1440×900 and 1920×1080 in English and Simplified Chinese. The actual viewport screenshots are in `docs/media/v1.4.0/`.
- Python tooling: 69 tests, 1 skipped; Web loader: 26 tests passed.
- Local Windows, macOS and Web exports passed; the local macOS packaged self-test passed.
- [Release PR CI](https://github.com/Jerryszz02/pokerGame/actions/runs/35844994398) passed rules, Windows and macOS native package checks, and Web export. Coach Worker checks also passed.
- Upload preflight validated all three manifests, source commit, archive layout, size and SHA-256. Butler reported all three channels complete at version 1.4.0.
- Authenticated `butler push-preview --changes-only` compared every remote file with the local package: zero new, modified or deleted files; 17 Web, 9 Windows and 24 macOS files unchanged.

## Limits

Windows graphical gameplay and Intel Mac gameplay were not manually revalidated. macOS remains ad-hoc signed and not notarized. Browser runtime acceptance is separate from package upload and signature verification; package manifests retain `public_release_ready: false`.
