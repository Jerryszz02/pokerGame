# PokerGame 1.2.0 — Browser play, two languages, and table audio

- Adds an itch.io Web build alongside Windows x64 and macOS Universal downloads. The Web build retains the existing threaded AI and requires WebGL 2.0 and SharedArrayBuffer support.
- Adds English / 简体中文 selection in Settings, including tutorials and replay controls.
- Adds lounge background music and card/chip sounds, with separate music and sound volumes. Browser audio starts after a click or key press.
- Keeps existing rules, AI decisions, save formats, tutorials, statistics and replay behavior unchanged by the Web export.

Desktop saves remain in the existing application data directory. Browser saves use IndexedDB and stay within the same browser profile/device/origin; they do not sync with desktop saves or an itch.io account. Clearing site data or using private browsing can remove access to progress. Unfinished matches cannot be resumed after closing or refreshing the game.

Use a mouse and a display area of at least 1280 × 720. Desktop Chrome/Edge are the initial browser targets; use a desktop download if your browser cannot run the threaded build. Local preview was tried by the user without reported issues; this does not establish the full browser or device compatibility matrix.

Windows builds are unsigned. macOS builds use ad-hoc signing and are not Apple-notarized; Intel Macs have not been separately validated. Extract desktop ZIPs into a fresh folder and verify the accompanying SHA-256 checksum. No game account, real-money wagering, external AI service or game telemetry is added.
