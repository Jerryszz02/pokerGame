# Media index

Keep reusable artwork at this directory's root and release-specific screenshots and devlog covers under `v<version>/`. Preserve the original banner when creating a version cover.

| Path | Purpose |
| --- | --- |
| `pokergame-banner.png` | Original banner and source for devlog covers. |
| `pokergame-cover.png` | Reusable storefront catalog cover. |
| `poker-room-background.png` | Reusable storefront background. |

| `v1.2.0/cover.png` | User-supplied v1.2.0 devlog cover. |

The existing gameplay screenshots belong to v1.0.0, as identified by the capture source's `project.godot` version. See [storefront asset provenance](../storefront/README.md#assets) for capture details. Moving these images does not refresh them to a newer release.

For future devlogs, save actual game captures as `v<version>/<feature>.png` and the banner-based cover as `v<version>/cover.png`. Upload them into the corresponding unpublished draft; the user handles publication. Follow the full [devlog requirements](../../AGENTS.md#devlog-requirements).
