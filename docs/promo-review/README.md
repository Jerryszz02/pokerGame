## 审核与证据边界

- [量化标准](rubric.md)：100 分制，至少 85 分且无硬性失败。八项分值为规格 10、来源 15、连续性 20、可读性 15、叙事 15、平台适配 10、声音 10、CTA 与授权 5。
- [R0 审核](review-R0.md)、[R1 复审](review-R1.md)、[R2 审核](review-R2.md)与 [R3 复审](review-R3.md)由未参与剪辑实现的独立 agent 维护，包括逐项得分、时间码、文件 SHA 和问题关闭证据。
- 三条横版第一轮修订补入可见的开始按钮与实际操作；教程反馈与对应牌面同时展示；英文主线补足摊牌；小红书结果字幕与揭晓同步；音频增加编码后的峰值余量。
- R2 根据用户反馈加入中心弹出的 5° 斜横幅和独立侧入大字；英文章节实际字身由约 54 增至 83 px，中文由约 57–58 增至 87–88 px，主要标题在 640×360 可读。新增[量化门槛](rubric-R2-addendum.md)覆盖动效、尺寸、停留时间、安全区和零遮挡，不能用总分抵消硬性失败。
- R2 的英文设置标题遮挡人数箭头；小红书字幕还遮住盲注数值，后者是本轮发现的 R1 漏检。两项在最后一次 R3 一并修复：标题拆为两行，字幕底板移至 y968 以下。R2 中文版已通过，保持 R2；Shorts 的 R0 文件 SHA 未变。
- 四条最终视频均完成 FFmpeg 全长解码、帧率 / 画幅 / 时长核对、响度 / 真峰值检测及关键帧检查。没有检测到异常黑场或长静音。
- 三条新横版的 AAC 内容哈希均与 R1 相同；源片入出点、时长、真实手牌顺序及字幕时码保持不变。
- **工具无法实际听音。** 主观音乐观感、感知爆音与音画同步仍为未验证软项，已在评分扣分。客观音频数据合格不代表已经试听通过。
- 全部画面来自 Godot 图形 MovieMaker 与真实 UI 操作，未改牌或改结果；教程展示当前三手引导中的 G1。镜头裁切、几何标题、操作圈为后期叠层；没有录制桌面鼠标。未把这些画面称为公网浏览器运行验证。
