## 审核与证据边界

- [量化标准](rubric.md)：100 分制，至少 85 分且无硬性失败。八项分值为规格 10、来源 15、连续性 20、可读性 15、叙事 15、平台适配 10、声音 10、CTA 与授权 5。
- [R0 审核](review-R0.md)与 [R1 复审](review-R1.md)由未参与剪辑实现的独立 agent 维护，包括逐项得分、时间码、文件 SHA 和问题关闭证据。
- 三条横版第一轮修订补入可见的开始按钮与实际操作；教程反馈与对应牌面同时展示；英文主线补足摊牌；小红书结果字幕与揭晓同步；音频增加编码后的峰值余量。
- 四条最终视频均完成 FFmpeg 全长解码、帧率 / 画幅 / 时长核对、响度 / 真峰值检测及关键帧检查。没有检测到异常黑场或长静音。
- **工具无法实际听音。** 主观音乐观感、感知爆音与音画同步仍为未验证软项，已在评分扣分。客观音频数据合格不代表已经试听通过。
- 全部画面来自 Godot 图形 MovieMaker 与真实 UI 操作，未改牌或改结果；教程展示当前三手引导中的 G1。镜头裁切、几何标题、操作圈为后期叠层；没有录制桌面鼠标。未把这些画面称为公网浏览器运行验证。
