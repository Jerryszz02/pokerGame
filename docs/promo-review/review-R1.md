- 对实际最终 MP4 独立计算 SHA-256，使用 FFprobe 核对规格，以 FFmpeg 全长抽帧覆盖完整时间线，查看每秒代表帧及关键修正点的 `960×540` 缩小预览。

- 对新增英文 / 中文配置补录重新计算 SHA-256，与 capture manifest 匹配；原七条来源已在 R0 独立核验。核对补录 UI 事件记录、真实开始按钮及进入牌桌画面。
- 独立复测最终 AAC 音轨响度、true peak 和长静音；核对客观 QA 的全片解码及黑场结果。
- 声音感知限制与 R0 相同：工具明确不支持音频输入，未实际听音。主观音乐观感、爆音感知和感知同步保留 Unverified，并在声音项扣除相关验证分；不虚构试听通过，也不新增 rubric 没有规定的硬门槛。
