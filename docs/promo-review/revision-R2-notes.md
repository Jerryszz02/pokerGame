# 横版标题强化 R2 制作记录

日期：2026-10-15。用户在 R1 交付后要求三个横版的文字更明显，开头使用从中心弹出的斜大横幅与从侧面滑入的大字。Shorts 保持 R0 成片。

## 改动

- Store / Xiaohongshu 开头使用 `CALL OR FOLD?`；Bilibili 保留 `这手，怎么打？`。浅金色横幅以中心为原点弹出，倾斜 5°；独立文字层从右侧滑入，0.4 秒后停稳。
- 开头用同一源片、同一时刻的手牌与操作区双窗口保留真实选择；没有重绘牌面或按钮。开场源片入出点与总时长不变，原始音轨仍只由背景实录播放一次。
- 横版主要章节标题由深底浅字改为浅金底深字。字号英文 82→128、中文 62→94；这些是制作参数，实际字身高度、对比与缩小可读性由独立审核测量。
- 英文观察对手段标题改放左上；中文下一手段标题改放右上，给原始手牌、公共牌和操作区留出空间。教程反馈辅助标题与小红书中文字幕也加粗放大。
- 镜头时长、源片入出点、关键点击、真实摊牌、同手回放与 CTA 时长保持原安排。Shorts 源码中的竖版样式分支保持原输出，交付复用已审核的 R0 文件。

## 证据与轮次

本次是三条横版的第二次修改 R2；若审核未通过，只剩一次 R3 修改额度。旧 R0、R1 与原 `delivery/` 不覆盖。

R2 文件与证据保存在 canonical 工作区的 `export/promo/v1.4.0/production-2026-10-15/revisions/R2/`：

- `source-snapshot/`：渲染前冻结的源码、依赖锁与导出脚本。
- `metadata/edit-manifest.json`：来源 SHA、原片帧段和成片帧段；开场额外记录 `handCrop` 与 `actionCrop`。
- `metadata/design-changes.json`：动效参数与改动范围，属于制作说明，不代替验收。
- `preflight/`：排版检查图，部分图片早于最后两处标题位置修正；正式验收只用最终 MP4。

验收依据为[原标准](rubric.md)与[独立制定的 R2 补充标准](rubric-R2-addendum.md)。最终审核状态以 `review-R2.md` 为准；本制作说明不自行宣告通过。主观听音限制继续保留。
