# R2 标题强化：独立审核补充标准

锁定日期：2026-10-15。依据用户对前三条横版成片的新反馈制定：文字更明显，尤其开头采用中心弹出的斜大横幅及从侧面滑入的大字。此文件由独立审核 agent 维护，审核者不参与制作代码或时间线实现。

## 适用范围与通过规则

- 仅适用于 **Store、Xiaohongshu、Bilibili 的 R2**，若有修复也适用于 R3。Shorts 不修改，维持 R0 已审核文件及结论。
- [原 rubric](rubric.md) 的 100 分、至少 85 分、全部原有硬门槛通过、声音证据限制等规则均保持；[R1 审核](review-R1.md) 和 R0 记录不覆盖。
- 本补充是对新需求的额外验收，**T1–T6 必须全部满足**才能将 R2 / R3 标为 Pass。新增要求未达标时，即使原评分超过 85，也须报告 Fail，并明确是新需求未满足；证据不足写 Unverified，不能视为通过。
- 不增加总分，也不追溯改变旧版分数。标题的字号、对比及阅读时间计入原“文本与主体可读”项；动效、先强调后操作的顺序计入原“叙事与节奏”项；安全区与平台差异计入原“平台适配”项；不得靠重复加分掩盖问题。
- 本次为每条横版的 **第二次修改 R2**；之后至多还有一次 R3。不得重置轮次或降低标准。R0、R1 与旧交付文件保留。

## T1：开场形式与时间

三条横版均须在前 3 秒出现明确的选择问题。Store / Xiaohongshu 主标题为 **CALL OR FOLD?**，Bilibili 主标题为 **这手，怎么打？**。

| 检查 | 量化门槛 |
| --- | --- |
| 中心斜横幅 | 稳态横幅主体中心距离画面中心不超过宽、高各 10%；可见主体宽为画幅的 65–88%，稳态倾角绝对值 3–10°。倾斜须在实际图像中可辨，不能仅在实现参数中存在。 |
| 中心弹出 | 横幅从中心附近放大出现，在入场期间可测得至少 20% 的尺寸增长；入场不只是透明度变化。横幅中心的入场轨迹不得变为明显从画外横向搬入。 |
| 侧入大字 | 主标题与横幅有可区别的运动；文字从左侧或右侧进入，入场水平位移至少为画幅宽的 20%（1920 px 下为 384 px）。不能仅与横幅一起缩放。 |
| 完成入场 | 从片头开始至横幅和全部主文字入场完成，不超过 0.65 s（30 fps 下至多约 20 帧）。 |
| 稳定阅读 | 全部主文字完整、清楚、接近静止的共同时间至少 1.50 s；动画进出过程不计入此时间。稳态允许细微装饰变化，不允许继续摇摆、缩放而影响阅读。 |
| 交回游戏 | 至 2.80 s，开场强调层已退出，或已移至不遮挡关键游戏信息的位置；仍需满足 T5 的动作前清空要求。不得以延长全片方式挤掉原有关键操作、结果或 CTA。 |

横幅背景边角可延伸至文字安全区外；主文字的完整稳态必须满足 T4。侧入开始时的有意画外位置不作为完整阅读时间，也不能把最终停稳后的截字称为入场效果。

## T2：标题确实更大、更清楚

所有尺寸以最终 1920×1080 图像中的**实际文字墨迹高度**为准，排除阴影、描边扩张、底板和旋转造成的外接框增长；不能仅用 CSS / SVG 的 font-size 代替画面测量。

| 检查 | 量化门槛 |
| --- | --- |
| 开场主文字 | 稳态可见英文大写字身或中文正文实际高度至少 **80 px**；主要文字块占画幅宽 **45–85%**。标点、空格不单独按字身高度检查。 |
| 后续章节标题 | R2 中所有与 R1 对应的主要章节标题，实际字身高度至少为 R1 的 **1.25 倍**，且不得低于 **48 px**。需用同一标题的稳态帧比较，不能比较 R1 的小字副标题与 R2 的大标题。 |
| 对比 | 各主要标题的正文填色与紧邻底板的相对亮度对比至少 **4.5:1**。有多种正文填色时逐色检查；直接叠在游戏画面上时，需确保稳态全程的实际背景仍满足，而非只选一帧最暗背景。描边、阴影可辅助，但不代替合格底色 / 底板。 |
| 阅读时间 | 每个章节标题完整清楚停留至少 **1.50 s**，沿用原标准；片段短时可提前引入标题或保持不遮挡的安全位置，不得靠缩短阅读时间换大字。 |

此处“章节标题”指剪辑添加的主要段落标题。游戏 UI、教程原文、普通中文字幕、辅助标签及 CTA 网址不强制放大到章节标题级；它们仍须满足原可读性与遮挡要求。新增辅助字不能被用作替代主要标题以规避比较。

## T3：实际缩小预览

- 在 **960×540** 检查全片全部标题、游戏关键操作、牌面、金额、教程反馈和 CTA，沿用原标准。
- 新增 **640×360** 的横版预览检查：开场主文字和每个主要章节标题必须能不放大地完整读出，字符不糊成块，细笔画不消失，换行不破坏含义。
- 不因新增 640×360 标题检查而要求整张游戏桌的所有辅助 UI 在该尺寸可读；核心游戏语义仍按原 960×540 检查。
- 审核记录每个标题的时间码、R1 / R2 字身高度、完整停留时间以及缩小预览结论。参数合格但实际缩小后不可读，仍不通过。

## T4：安全区及平台关系

- 1080 横版的主标题及 CTA 稳态正文外接框，含实际旋转后字形，须位于 **x = 96–1824、y = 54–1026** 的 5% 文字安全区内；正文不能截字或贴边。
- 大字、章节标题、普通字幕与 CTA 之间不得重叠。标题底板不能使其他必要文字变得不可读。
- Xiaohongshu 与 Store 维持相同时长、镜头、英文标题和标题动效；中文普通字幕仍完整保留、不超过 **8 字/s**，不与新大字碰撞。Bilibili 游戏界面和主要标题保持中文。
- 本轮不修改 Shorts；其交付文件必须与已通过版本 SHA-256 `ba3767cc7cd06c08db2730b3e4359dc1087072fba0749df15215c70c40bf2233` 相同。

## T5：强调不能遮挡操作与结果

- 每个新动效必须列明覆盖区间及所处镜头；大横幅若覆盖游戏区域，只能放在独立的操作前强调时段，不得在同时需要读牌面、金额、按钮、反馈或结果时遮住它们。原关键内容零遮挡要求不变。
- 以真实 UI 事件 / 源帧定位每次关键点击：**点击前至少 0.20 s**（30 fps 为 6 帧）到动作结果清楚呈现期间，强调层不得与按钮、关键牌面、金额、教练反馈或结算文字相交。安全角落的非遮挡标题可保留。
- 对按钮、牌面、金额、教程反馈、回放视角状态和结果逐项核对，新增叠层导致的关键遮挡帧数必须为 **0**。不能以透明度较低为由接受影响辨读的叠层。
- 保留已修复的配置开始按钮与进入、教程反馈及对应牌面、同手真实摊牌及结算。结果仍需至少 **2 s** 清楚静留；结尾 CTA 仍需连续至少 **4 s** 稳定。
- 如果改动导致源入出点、点击位置、结果时长或手牌顺序发生变化，必须更新 manifest 并重新验证实际连续性。旧 R1 通过结论不能代替改动后的检查。

## T6：成片身份与复验方法

1. 只在收到实际最终 R2 MP4 后进行成片判定。按每条文件记录 SHA-256、版本和修改轮次；审稿图片、代码或预览页均不能代替最终 MP4。
2. 对每条完整时间线复核；片头前 3 s 和每个新动效入出场按最终帧率逐帧检查，关键点击附近至少覆盖前后各 0.50 s。记录横幅尺寸、中心、倾角、入场完成点、侧移距离和共同稳态时长。
3. 对标题稳定帧做 R1 / R2 尺寸比较、对比度检查、两档缩小预览；完整标题和关键 UI 保护区域以实际画面为准。参数 / manifest 是定位证据，不替代实际画面。
4. 复核原媒体规格、完整解码、黑场、音频响度与 true peak。若 R2 原封不动复制音轨，可以音频内容哈希与 R1 比对作为补充；最终 MP4 的规格与文件身份仍需检查。
5. 若工具仍不能听音，继续保留主观听音及感知同步 Unverified 的原限制，不将音量数据写成实际听音结论。
6. 在新建的 `review-R2.md` 中输出原八项评分、T1–T6 逐项结果、硬门槛结论、实际方法与限制、带时间码的问题。保存原轮次审核与交付，不能用新版覆盖旧结论。
