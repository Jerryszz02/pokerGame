Browser: launch the game on this page. Desktop Chrome or Edge with WebGL 2.0 and SharedArrayBuffer support is recommended. Click or press a key to start audio. Browser saves are local to this browser and device; unfinished matches cannot be resumed after refreshing.

Windows: download the Windows x64 ZIP, extract the entire archive, and open PokerGame.exe.

macOS: download the macOS Universal ZIP, extract it, and open PokerGame.app. You can move the app to Applications.

No Godot editor or .NET installation is required. Choose English or 简体中文 in Settings. Use a mouse and a display area of at least 1280 × 720.

The Windows build is unsigned and may trigger SmartScreen. The macOS build uses ad-hoc signing and is not Apple-notarized; macOS may show a first-launch security prompt. Review the release notes and your system’s prompt before deciding whether to open it.

Download the accompanying SHA-256 checksum files to verify the ZIPs. Read the 1.2.0 release notes. For problems, report your version, system, and steps on GitHub.
